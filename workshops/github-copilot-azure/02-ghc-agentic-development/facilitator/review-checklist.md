# Facilitator review checklist

Use this after the solution demo.

- [ ] The issue states observable behavior and non-goals.
- [ ] Repository and path-scoped instructions agree with the implementation.
- [ ] The agent definition constrains scope and forbids invented evidence.
- [ ] Acceptance tests cover success, `429`, `Retry-After`, independent clients,
      window reset, validation, and the large-cart regression.
- [ ] The review maps every claim to a test or code location.
- [ ] The command shown on screen is copied from the workshop, not remembered.
- [ ] No fixed model response or fabricated terminal transcript is presented.
